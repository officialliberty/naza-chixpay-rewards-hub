# ChixPay profile and appearance

## What will be added
- A dedicated profile screen opened from the member avatar on the dashboard.
- Profile photo selection, preview, upload, replacement, and saved display across return visits.
- Account details showing the member’s name, email, phone number, state, and Chix ID status.
- A clear Light / Dark appearance selector that applies immediately and remembers the choice on the device.
- A secure Log out action that ends the session and returns to the ChixPay landing screen.

## Data and privacy
- Add an optional profile-photo field to member profiles.
- Add a private profile-photo storage area where each signed-in member can manage only their own image.
- Keep existing profile and account restrictions unchanged.

## Interface details
- Preserve the existing blue, green, yellow, rounded glass design in both modes.
- Replace the dashboard initials with the saved profile photo when available.
- Include upload progress, image validation, success feedback, and failure messages.
- Keep controls readable and usable on mobile and desktop.

## Verification
- Test opening the profile, switching both appearance modes, uploading a photo, refreshing to confirm persistence, and logging out.
- Check the dashboard and profile screen at mobile and desktop sizes.
